# Changelog

Публічні релізи. Теги ті самі, що в моїй базі: calver `vYYYY.MM.N`, пропуски номерів нормальні. Як оновитись і відкотитись: [README.md](README.md).

## v2026.11.26 (README: план встановлення, готові промпти, звіт і нові розділи)

- README українською й англійською: перевірка вимог, план першого встановлення з очікуваним результатом на кожному кроці, готові промпти для Claude Code (перше встановлення, перевірка, звіт про встановлення, оновлення, відкат), речення про те, що install не шукає проєктів, а правила й хуки діють глобально.
- Нові розділи README: відкат від легшого до важчого (rollback, Claude без жодної команди, знімок, повне прибирання бази) і дрібні випадки; Context7 у вимогах; облік часу (claude-time, скіл time-register, щотижнева задача за розкладом); документи поза git (docs-sync: репо документів, його приватна копія на GitHub, підключення проєкту); звірка з ECC (ecc-drift).
- `docs/FORK.md`: цикл зміни для своєї копії бази (перевірки, свій тег, install, відкат, оновлення з upstream). `docs/adr/`: ADR-001 (встановлення копією з маніфестом) і ADR-002 (бюджет глобального файла правил і rules).
- Правила, хуки, агенти, скіли й інструменти ті самі, що у v2026.11.25: оновлення не змінює в `~/.claude` нічого, крім тегу в маніфесті.
