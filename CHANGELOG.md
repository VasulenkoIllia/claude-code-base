## v2026.11.31 (реліз 1.1: хук push-allow, блок друку env-файлів, effort рев'юерів; релізи виходять одразу)

- Цей тег вийшов як GitHub Release «1.1». З нього публічний реліз виходить одразу після кожного релізу моєї бази, а GitHub Release на кожен тег, з назвами підряд: 1.2, 1.3 і далі. Версією для оновлення лишається тег calver `vYYYY.MM.N`. Тегів v2026.11.29 і v2026.11.30 тут немає: їхні зміни входять у цей реліз.
- Хук `push-allow` (подія PermissionRequest): `git push origin <feature-гілка>` іде без вікна дозволу, коли хук прочитав усю команду, а решта команд у ній зі списку безпечних. Push у main, master, develop, staging та інші захищені гілки, push тегів, без назви гілки, з `-C` і в інший remote питає, як і раніше. Умови: `docs/USAGE.md`, розділ 2.
- bash-guard: друк env-файла (`cat`, `head`, `tail`, `less`, `grep`, `sed`, `awk` на `.env` і файлах `<назва>.env`) і `docker compose config` тепер блокуються з підказкою, яка форма проходить; раніше це був запит. Проходять файли-зразки (`.env.example`), тихі форми на кшталт `grep -c KEY .env`, вивід із маскою після `|` і `docker compose config -q`. `rm -r` блокується ще й у формах `\rm`, `/bin/rm`, у дужках і на теках першого рівня дому.
- settings: Claude не читає `.env.staging`, `.env.stage`, `.env.development`, `.env.dev`, `.env.test` і файли `*.env`; запит дозволу на `gh repo create --public`, `gh repo edit --visibility`, `git -C <тека> push` і термінал застосунку.
- session-hint: після зеленого CI Claude одразу викликає `gh pr merge`, вікно дозволу і є вашим рішенням.
- Шість агентів-рев'юерів працюють з `effort: xhigh`. Прибрано два вендорені скіли ECC, якими я не користувався: api-design і documentation-lookup; install прибере їх з `~/.claude/skills`, копія лишиться у знімку.
- doctor: рядок `docs state` на проєкт (завеликий STATUS, журнал чи memory) і рядок `docs repo origin` (чи приватний репо, куди docs-sync пушить документи). Глобальний файл правил коротший на 154 байти.
- Після оновлення перезапустіть усі сесії Claude: нові дозволи й хук `push-allow` діють лише в сесіях, стартованих після install. Якщо блок друку env-файлів заважає: `bash scripts/rollback.sh v2026.11.28`.
